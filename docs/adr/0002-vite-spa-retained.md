# ADR 0002: Vite-SPA bleibt erhalten

- Status: Akzeptiert
- Kontext: Vite/React/TypeScript baut erfolgreich; kein technischer Blocker für SPA-Routing ist belegt.
- Entscheidung: Vite bleibt, React Router wird ergänzt; kein Wechsel zu Next.js.
- Konsequenz: Server-seitige sensible Funktionen laufen über Supabase Edge Functions.
